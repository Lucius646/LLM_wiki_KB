# Mamba Notes

Mamba is presented as a selective state space model that aims to keep linear-time sequence processing while improving content-based reasoning compared with earlier state space approaches.

Compared with transformer attention, the main contrast is not simply “better” versus “worse”. Attention provides explicit token-to-token interaction, while Mamba emphasizes efficient sequential state updates and selective propagation through long contexts.
